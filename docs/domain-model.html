POC MDM – Modèle des données enrichies

Couche domaine du prototype. Les noms en italique gris sont ceux du code, eux aussi dans le langage du domaine.

Une source affirme une valeur : c'est une valeur sourcée, datée et tracée. Le MDM rassemble toutes les valeurs sourcées d'un même attribut, applique les règles qualité, puis présente une donnée consolidée : la valeur retenue, sa qualité, et tout ce qui l'explique (sources concordantes, conflits, valeurs rejetées, historique).

Comment lire une donnée consolidée

SituationRègle appliquée par le MDMCe que voit le métier
ÉvolutionLes sources donnent des valeurs à des dates de valeur différentes : la plus récente est la valeur courante.Valeur courante + historique
ConcordancePlusieurs sources donnent la même valeur à la même date de valeur : la confiance augmente.Plusieurs entrées dans sources
ConflitPlusieurs sources donnent des valeurs différentes à la même date de valeur : la source la plus fiable l'emporte, la confiance baisse, une revue est demandée.statut: conflit, alternatives, aRevoir
RejetUne valeur échoue à une règle bloquante : elle n'est jamais retenue, mais reste visible.rejetees avec le contrôle en échec
AptitudeUne règle liée à un usage (ex. fraîcheur pour la RCP) n'écarte pas la valeur : elle dit seulement si elle convient à cet usage.qualite.aptitude
